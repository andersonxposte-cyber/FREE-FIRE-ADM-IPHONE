# FREE FIRE ADM ORGANIZER — versão web para iPhone

Esta é uma versão web instalável (PWA) inicial. Não é um ficheiro IPA e não é uma aplicação nativa da App Store.

## Publicar no GitHub Pages
1. Envie todos os ficheiros desta pasta para a raiz do repositório GitHub.
2. No repositório, abra Settings → Pages.
3. Em Build and deployment, selecione Deploy from a branch.
4. Escolha `main` e `/ (root)`, depois Save.
5. Aguarde a publicação e abra o endereço GitHub Pages no Safari do iPhone.

## Adicionar ao ecrã inicial do iPhone
No Safari, abra o endereço publicado → botão Partilhar → Adicionar ao ecrã principal.

## Limitações desta versão
É um protótipo funcional inicial: apostas, campeonatos simples, notas e saldo ficam guardados localmente no navegador. Não inclui sincronização entre dispositivos, gestão completa de torneios, exportação PDF/Excel, autenticação, nem assinatura IPA. Os dados podem ser perdidos se os dados do site forem apagados. Faça cópias de segurança.
